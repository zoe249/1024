# 闯关场景搭建说明

日期：2026-10-28。闯关使用独立场景与玩法脚本，设置界面按2026-10-30反馈复用现有展示组件。

## 2026-10-30 复用设置面板

将现有设置样式整理为`assets/resources/base/Settings/SettingsPopup.prefab`，闯关场景直接放置关联实例，替换此前单独搭建的暂停面板。面板、标题、音量行、滑块、图标及按钮均由静态层级维护，沿用已有美术和`PauseOverlayController`的滑入／滑出表现，不新增位图。设置图标入口位于左上角，返回按钮位于右上角。无尽场景不改。

关闭恢复、重玩当前关卡、返回首页由闯关控制器注入回调；声音使用原存档键并作用于LevelSfx音效通道；分享沿用平台适配器。设置层位于Canvas下，面板跟随设计比例，遮罩覆盖全部可见区域。设置组件增加可重复调用的`dispose()`，兼容宿主组件单独移除及子节点先销毁；宿主不手动调用子组件生命周期。

检查覆盖静态预制件不补建节点／不重复加载美术、音量持久化、关闭与重玩、返回延迟到触摸派发结束且只提交一次、普通屏与长屏遮罩和重复清理；不替代Creator／微信实际验收。

## 2026-10-29 选列交互

输入改为按下选列、拖动换列、松手落子。按住期间仅显示当前列的暖白柔光带，只更新选列反馈，不推进棋盘、出子或存档。最终按松手位置提交一次落子；拖出棋盘松手、触摸取消、暂停、停用、重开、离场或布局变化会取消本次选择。每次只跟踪首根有效手指，其他手指的移动、松手与取消不影响当前选择。满列仍高亮当前列并提示换列，松手不消耗棋子。

根据视觉反馈，已删除`LandingMarker`棋子落点方框，以及列的左右边线和上下封口。`ColumnHighlight`仍为Board下、PieceLayer之前的静态节点，使用原生Graphics顶点透明度生成无描边光带：暖白色、最高约44%不透明度（2026-10-30由25%增强），左右羽化、上下平滑渐隐。几何仅在尺寸／颜色变化时生成，按住、换列和再次显示复用缓存，不新增位图资源。闯关控制器只切换显示与位置。

交互检查覆盖按住等待、拖动、松手位置、多指隔离、越界、取消、满列、暂停、停用与重开；标准与Creator loose编译均通过。已用组件实际绘制数据在草地背景上检查光带可见度，属于样式检查，不替代Creator／微信实际触摸验收。

## 2026-10-29 动画对齐

修正初版闯关把合并做成吸附缩小、重力缓慢加速且缺少反馈的问题。当前按无尽模式实际代码对齐：手动快速落子为5000单位／秒匀速；重力0.09秒quadOut；周围棋子留在原格，按最多0.036秒错帧舒展后淡出，仅上浮格宽的2.5%；开始消除0.1秒后锚点切换数值，按0.13／0.115／0.065秒三段回弹。消除和升级重叠，总时长0.41秒；同一批全盘合并并发播放，不再逐组串行。

升级爆点、闪光、碎片、连击字效及其位置／配色／时序移植到闯关专用脚本。场景静态增加FxLayer和LevelSfx，绑定相同的碰撞、合并和连击音效资源，每批只播放一次。暂停冻结棋盘动作和所有临时特效；重开、返回与销毁清理登记。独立数字块补回高光与皇冠层，14档数值的数字颜色、字号、间距、描边和偏移对照无尽版。

验证新增`tools/verify-level-animation.cjs`，直接从当前无尽实现捕获Tween轨迹，以120Hz采样对照闯关消除与升级曲线，并对照四种特效及五档连击字效的节点、参数和动作记录。闯关运行时仍不导入无尽脚本；测试读取无尽代码作为参照。

## 入口与静态层级

首页 `home.scene / Canvas / Main / StartPageOverlay / PageCard / HomepageArtwork / LevelEntryButton` 提供“继续闯关 · 第N关”按钮，直接进入 `level.scene`。无尽模式入口和脚本保持原状。

```text
level.scene
└─ Canvas
   ├─ Camera
   ├─ MeadowBackground
   ├─ LevelRoot [LevelSceneController]
      ├─ Header：返回、暂停、关卡名称、目标提示
      ├─ Goals：两个静态目标卡，目标数字／剩余数量／收集槽
      ├─ Queue：当前数字块、下一颗预览
      ├─ Board：5×7开放草地棋盘
      │  ├─ ColumnGuides：静态竖向落列引导
      │  ├─ ColumnHighlight：无描边、四周渐隐的当前列光带
      │  ├─ PieceLayer：运行时数字块与木块
      │  ├─ IceLayer：固定格子冰层与破碎效果
      │  └─ FxLayer：临时消除／升级和连击特效
      ├─ LevelSfx：静态音效通道
      ├─ ActionHint
      └─ ResultOverlay：遮罩、结果、下一关／重试、首页
   └─ PauseOverlay：SettingsPopup预制件实例，音量、关闭、分享、重玩、返回
```

UI、文字节点、遮罩和按钮都在场景中维护；普通UI不由脚本搭建。运行时动态部分限于棋子、冰层与临时特效。场景按750×1334适配，背景独立铺满，界面避开安全区与微信右上角胶囊。

## 规则和进度

- 当前数字悬停，按下／拖动只选列并预览，松手在有效列后才下落；只预览下一颗。动画中输入锁定，满列不推进出子。不设步数、计时、道具或得分。
- 四向同值连通块整体合并，n颗数字v产出v×2^(n−1)。先落点局部连锁与相关列重力，再全盘重力、连通块扫描，直到稳定。
- 收集只记录真实合并产物的精确数值，收集到的数字仍留在棋盘。三颗2产出8，不计一次4。
- 冰层固定在格子，合并成员所在格去冰，经过或普通落地不去冰。最后一次破冰完整落地收尾后再显示结算。
- 木块固定不移动，不参与合并、不被消除，并把列分为独立重力区间。
- 稳定后先判通关，再判满盘失败。通关解锁下一关；第3关完成显示当前关卡全部完成，可重玩。
- 设备本地存档键为`number-garden-level-progress-v1`，不写入无尽续局或云同步。动画中离场恢复上一稳定检查点，整次落子可重新操作；不保存半场合并。
- 固定出子序列循环使用，没有操作次数上限。三个关卡用于首版闭环，尚未作难度与长期留存平衡。
