# 超越目标与结算名次：实现与验证

日期：2026-10-19，记录 HUD 与旧版名次阶段。2026-10-20 新版结算替换旧版，当前实现与验证见 [新版结算实现验证](新版结算-实现验证.md)。

## 已实现

- `assets/resources/Gameplay/ScoreTargetHUD.prefab`：248×162 静态结构、固定得分区、双槽目标和裁切窗口；数字为实时 Label，复用 Eazy 字体及现有头像，无新增 PNG。Prefab 约 34 KB。
- `OvertakeTargetWidget`：独立分数补间、140ms 头像轻弹、140ms 旧目标退出、220ms 新目标进入；昵称省略、头像代次保护、最新目标合并、暂停/隐藏收敛和销毁清理。
- 真机反馈后的右对齐修正：标题、当前分数、昵称、目标分数统一右边缘；头像按实际文字宽度向右收紧。上方字框改为 240 宽，字号不变，短分数不再因居中/左对齐留下大段右侧空白。浏览器原型仍作为动画节奏参考，本次对齐以实际 Prefab 为准。
- 榜首文案改为「已登顶」。当前及目标分数超宽时在固定字框内使用 SHRINK 缩小实际字号并显示完整数字；头像最多移至原文本区域左侧，不被大分数挤出。名次与目标选择继续使用原始分数，排版不参与计算。
- `OvertakeRivalStore`：先显示自己的历史最佳；严格超过才换目标，同分保留；无历史分本局不请求榜单；缓存、限流、退避和网络静默降级。
- `PlayController` / `PlayUIController`：纯数据状态接线，分数统一由新版 HUD 显示；旧分数条在场景中默认停用，运行时也不再绘制、刷新或作为加载回退显示。布局复用既有 Content 安全区和 BoardGeometry，不改棋盘或出生点。
- 结算按本局操作 ID 等待对应同步回执，3 秒超时后隐藏；支持首次上榜、持平、名次滚动和上升箭头。沿用现有弹窗文字样式，未新增未确认的绶带素材。
- 后端新目标接口、同步名次、已验证成绩生成列与索引，README 已更新。
