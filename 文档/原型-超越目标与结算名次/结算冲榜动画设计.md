## 画面

最新确认稿采用一张完整结算卡，将紧凑标题、分数、奖励和榜单整合在同一底板内。采用项目的彩铅平涂、奶油色、珊瑚橙与细暖棕轮廓。旧 HTML 用于查看冲榜节奏，其早期外观不再作为当前视觉定稿。

- 顶部小皇冠、珊瑚绶带、金边和奶油色「本局结算」烘入同一张 result-card.png，不再独立搭建标题。主分数为动态珊瑚橙数字，固定字框和单行 SHRINK，以七位至十位带千分位数字检查容量。
- 最高合成与金币在同一行，取消两枚小签。榜单仍约五行高，顶部显示名次与 `↑N`；本人行为珊瑚橙与细暖棕轮廓，其他玩家仅用轻淡分隔线。连续动画视口不放奖杯或填充插画。
- 原型底部用首页、珊瑚橙「再来一局」、叶绿分享演示三个操作。游戏接入按用户后续反馈保留原场景绑定的三张 v3 按钮 PNG，采用两枚方形图标和横向分享素材；分享按钮的最终游戏素材已按最新反馈改为蜂蜜金，见 [素材说明](结算分享按钮-素材说明.md)。不以 Graphics 重绘；本人行添加少量轻淡彩铅短线。
- 当前底板为 720×1112 的透明 PNG，内区为完全不透明的单一奶油色，没有花朵或叶片堆叠。静态标题按用户明确要求烘入，所有分数、奖励、名次与头像均由运行时节点渲染。
- 冲榜落位后，两侧喷出蜂蜜黄、珊瑚橙、叶绿和浅蓝彩纸，夹少量短彩带与星片，翻转后飘落。动态庆祝使用 Canvas，不新增位图素材；得分、头像、榜单正文和操作按钮留出保护区。
- 游戏场景背景、暗色遮罩和棋子保持原样。整窗基准 750×1360，榜单 Mask 632×500、行节距 96，保留五行落位空间。效果图、PNG 和检查 JSON 位于 design，说明文档留在文档目录。

## 动作

| 阶段 | 时长 | 表现 |
| --- | --- | --- |
| 弹窗入场（游戏接入新增） | 320ms | 遮罩 180ms 渐入；整张卡片轻浮、由 94% 到 101% 再收至 100%，前 160ms 渐显；入场稳定后才推进下面的冲榜时钟 |
| 看清起点 | 450ms | 自己在榜单底部，先显示原名次；得分已经是本局最终值 |
| 起跑 | 180ms | 自己的行下压 4px、轻微放大，保持水平 |
| 向上冲 | 1950ms | 自己从底部上升，名次连续减少，被超过的行依次下移一格；榜单向下滚动以展示更高位置 |
| 落位 | 340ms | 最后减速，停在第二行；轻微放大后回弹，同时触发两侧彩纸喷发 |
| 庆祝 | 2600ms，与落位重叠 | 两波彩纸相隔 180ms 喷出，逐渐翻转、下落、淡出；固定新名次和 `↑N` |
| 结束 | 停留 | 清空彩纸，保留清晰、稳定的榜单与按钮 |

常规演示为第 21 名升至第 13 名，冲榜与落位约 2.92 秒，彩纸在 2.58 秒时启动、5.18 秒时清空。登顶停在第一行，顶部保留「第 1 名」和实际增量，仅右侧小状态显示「已登顶」，三波彩纸共 144 片，庆祝延长至 3000ms；普通超越为两波共 96 片。大幅跃升演示为第 121 名到第 13 名，中段滚动压缩为 2100ms，冲榜与落位约 3.07 秒，庆祝在 5.33 秒结束；不为每个被超越者排队播放。彩纸不会阻止点击按钮。

上述冲榜和彩纸时间从入场结束开始计算；游戏正常入场额外增加 320ms，旧 HTML 仅供查看原冲榜节奏。遮罩与卡片分别处理异步加载，不因素材就绪而让遮罩再次闪回透明；重算安全区保持入场进度。关闭、停用和切后台时停止过渡并收敛，减少动态效果时直接显示。

上方得分和弹窗在入场完成后保持固定。冲榜时自己的行、被超越行、榜单视口内的内容及名次数字运动，头像、昵称和分数始终成组；落位后彩纸独立播放。播放一次后停住，提供重播与慢放，彩纸同步慢放，不自动循环。

## 特殊情景

- 名次持平：直接显示现有位置，无冲榜、箭头或庆祝。本局得分可以低于历史最高分，榜单仍展示历史最高分。
- 首次上榜：直接进入最终位置，显示「新上榜」，不编造原名次；450ms 后播放一波 36 片的小庆祝，持续 1900ms。
- 大数字和长昵称：分数完整保留并在固定宽度内缩小，昵称省略；布局和头像尺寸不随数字扩展。十位数情景包含同分玩家，用于检查显示容量。
- 减少动态效果：直接显示最终结果，不喷彩纸。切换情景、重播、离开页面或切到后台时取消旧动画并清空彩纸；窗口缩放时重新计算保护区。

## 接入边界

浏览器原型仍为固定示例数据，按钮只演示本地效果。实际游戏已使用 `/sync` 新增的 `settlement` 快照，包含按本局操作 ID 绑定的前后名次、本人和最多 56 条真实邻近记录；排序与公开榜一致，大幅跃升压缩中段。顶部本局分与榜单历史最佳分别显示。三秒无回执保留基础结算和可用按钮。见 [新版结算实现验证](../新版结算-实现验证.md)。
