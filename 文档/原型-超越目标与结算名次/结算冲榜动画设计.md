## 画面

替换现有结算弹窗的完整界面设计，采用新版商城、每日奖励中的彩铅平涂、暖棕描边和独立卡片语言。取消整块外层底板，保留游戏背景上的标题、得分、两枚小统计签与下方独立排行榜卡片，减少大面积面板的重量。

- 标题为奶油色描边字，得分放大为蜂蜜黄动态数字；最高合成与金币收成两个轻量小签。
- 排行榜单独使用浅奶油卡片，约五行高，顶部集中显示名次与 `↑N`；自己的行改为珊瑚橙，沿用相同暖棕轮廓，其他玩家保持轻淡。
- 底部统一为首页、珊瑚橙「再来一局」、叶绿分享三个按钮；主操作宽度更大。重玩按钮与自己的榜单行添加少量运行时彩铅短线，保持画面干净。
- 弹窗底板采用一张完整透明 PNG：蜂蜜金边框、顶部皇冠、珊瑚飘带、少量叶片与底部小星章。去掉花朵，中央保持纯奶油色；所有动态数据留在 HTML 中。
- 冲榜落位后，两侧喷出蜂蜜黄、珊瑚橙、叶绿和浅蓝彩纸，夹少量短彩带与星片，翻转后飘落。动态庆祝使用 Canvas，不新增位图素材；得分、头像、榜单正文和操作按钮留出保护区。
- 游戏场景背景、暗色遮罩和棋子预览保持原样。为皇冠留出顶部空间，略收紧得分区间距，榜单仍保持五行高度。底板图片已经内嵌；HTML、PNG 和 JSON 检查记录保存在 `design/原型-超越目标与结算名次/`，说明文档留在文档目录。

## 动作

| 阶段 | 时长 | 表现 |
| --- | --- | --- |
| 看清起点 | 450ms | 自己在榜单底部，先显示原名次；得分已经是本局最终值 |
| 起跑 | 180ms | 自己的行下压 4px、轻微放大，保持水平 |
| 向上冲 | 1950ms | 自己从底部上升，名次连续减少，被超过的行依次下移一格；榜单向下滚动以展示更高位置 |
| 落位 | 340ms | 最后减速，停在第二行；轻微放大后回弹，同时触发两侧彩纸喷发 |
| 庆祝 | 2600ms，与落位重叠 | 两波彩纸相隔 180ms 喷出，逐渐翻转、下落、淡出；固定新名次和 `↑N` |
| 结束 | 停留 | 清空彩纸，保留清晰、稳定的榜单与按钮 |

常规演示为第 21 名升至第 13 名，冲榜与落位约 2.92 秒，彩纸在 2.58 秒时启动、5.18 秒时清空。登顶停在第一行并显示「已登顶」，三波彩纸共 144 片，庆祝延长至 3000ms；普通超越为两波共 96 片。大幅跃升演示为第 121 名到第 13 名，中段滚动压缩为 2100ms，冲榜与落位约 3.07 秒，庆祝在 5.33 秒结束；不为每个被超越者排队播放。彩纸不会阻止点击按钮。

上方得分和弹窗本身保持固定。冲榜时自己的行、被超越行、榜单视口内的内容及名次数字运动，头像、昵称和分数始终成组；落位后彩纸独立播放。播放一次后停住，提供重播与慢放，彩纸同步慢放，不自动循环。

## 特殊情景

- 名次持平：直接显示现有位置，无冲榜、箭头或庆祝。本局得分可以低于历史最高分，榜单仍展示历史最高分。
- 首次上榜：直接进入最终位置，显示「新上榜」，不编造原名次；450ms 后播放一波 36 片的小庆祝，持续 1900ms。
- 大数字和长昵称：分数完整保留并在固定宽度内缩小，昵称省略；布局和头像尺寸不随数字扩展。十位数情景包含同分玩家，用于检查显示容量。
- 减少动态效果：直接显示最终结果，不喷彩纸。切换情景、重播、离开页面或切到后台时取消旧动画并清空彩纸；窗口缩放时重新计算保护区。

## 接入边界

浏览器原型仍为固定示例数据，按钮只演示本地效果。实际游戏已使用 `/sync` 新增的 `settlement` 快照，包含按本局操作 ID 绑定的前后名次、本人和最多 56 条真实邻近记录；排序与公开榜一致，大幅跃升压缩中段。顶部本局分与榜单历史最佳分别显示。三秒无回执保留基础结算和可用按钮。见 [新版结算实现验证](../新版结算-实现验证.md)。

原型庆祝阶段只更新 HTML、说明和检查记录。后续游戏接入已完成，最终 PNG 原样复制到 assets/resources/Settlement/honor-panel.png；游戏使用独立 Prefab 和 Graphics 庆祝。非文档交付物统一位于 design 目录，文档目录仅保留 Markdown。图片底板更新前的浏览器检查沿用历史记录；底板更新时已执行面板规格脚本、像素与 Alpha 检查、深底/奶油底素材预览、内嵌图片一致性、脚本语法和 320/375/430px 的布局推算。彩纸时序、数量、收尾与取消逻辑另作脚本模拟检查，不能替代浏览器视觉检查。新底板和彩纸的完整页面渲染尚未重新复核，当前效果以 HTML 为准；Creator 与微信真机未验收。详见素材说明。
