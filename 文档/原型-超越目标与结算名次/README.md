## 已确认

- 无背景签；标题「得分」；当前数字暖黄、目标数字奶油白，保留暖棕描边；所有文字水平。
- 生产 HUD 按最新真机反馈统一右对齐；上方得分字框与右边缘固定，下方头像贴近文字。1～7 位保留设计字号，超宽时缩小实际字号并保留完整数字，适配接口允许的 10 位最高分；设计原型用于核对动画节奏。
- A 头像轻弹 140ms → A 整组上退淡出 140ms → B 整组下方接入 220ms，目标交替共 500ms。
- 演示另有 220ms 计分补间，完整按钮演示共 720ms；这不改变 500ms 的交替时长。
- 目标两槽切换，稳定后隐藏旧槽；实际连续超越时只保留最新有效目标，得分和玩法独立更新。

## 验证边界

原型按钮使用固定演示数据，不连接排行榜。实际目标、网络、远程头像和暂停/恢复的代码验证另见实现记录，不能用浏览器演示替代游戏验收。
