# 无尽模式阶段晋级与能力三选一

日期：2026-11-02。

2026-11-03 调整：一次性打乱演出采用“弧线收牌 → 左右两叠交错洗三轮 → 逐张随机发回”，牌全程可见。允许连续落同列和不同列高，仅兜底不能全部回到同一列。

状态：首版已实施。晋级三选一为“斜向合并、万能来客、打乱”，斜向与万能在本局自动持续生效，打乱为一次性效果。首版采用下文建议值：合出 1024，5×7 进入 7×8，万能每第 6 颗出现。配置、预制件与验证范围见[实现与验证记录](无尽模式阶段晋级-实现与验证.md)。

## 1. 目标与已确认方向

当前无尽模式主要通过选列落子、合并和重力结算推进，棋盘全部填满后结束。新方案让玩家在一局中经历“完成任务 → 镜头拉远、棋盘增大 → 三选一 → 以所选效果继续游戏”。

斜向改变可以连接的位置，万能改变后续特殊出子的安排，打乱提供一次重新布置数字的机会。玩家继续选列落子，不增加反复点选源棋子与目标位置的操作。

| 项目 | 已确认方向 |
| --- | --- |
| 接入模式 | 当前无尽模式 |
| 晋级条件 | 首版默认合出 1024，可在 Inspector 调整为 2048；其他任务后续扩展 |
| 视觉效果 | 镜头拉远、视野变大，棋盘与原有棋子整体缩小 |
| 列数变化 | 一次增加两列，第一阶段 5 列进入第二阶段 7 列 |
| 行数变化 | 首版按建议增加一行，7 行进入 8 行 |
| 晋级选项 | 斜向合并、万能来客、打乱，三选一 |
| 斜向、万能 | 本局自动持续生效的增益 |
| 打乱 | 一次性效果，不按反复充能施放设计 |
| 拆分、传送 | 拆分留作另行讨论的新技能；传送撤出本轮方案 |

首版建议只验证第一阶段到第二阶段的一次晋级，一局只选择一项。1024 和 2048 作为首个任务的不同配置方案，不默认表示本局连续扩盘两次。重复晋级、多项效果叠加及更多候选另行设计。

## 2. 一局中的完整流程

1. 第一阶段正常落子，完成局部合并、重力与全盘结算。
2. 检查任务；未完成则按原规则检查满盘并继续。
3. 任务完成后冻结普通下落及其他棋盘操作，保存扩大后的棋盘与待选择状态。
4. 播放镜头拉远，完整的新盘面进入视野。
5. 弹出斜向／万能／打乱三选一，确认后保存选择。
6. 斜向立即启用八向并完成一次全盘结算；万能启用后续特殊出子规则；打乱立即重排一次并结算。
7. 所选效果处理完成后，继续普通出子与第二阶段对局。

演出、弹窗及选择后的处理期间不生成下一颗，不重抽或额外消耗已展示的预览。第一阶段及选择万能、打乱的第二阶段保持四向连接；只有选择斜向后才启用八向。

原有锤子、炸弹、交换保留库存及广告规则，与晋级选择分别处理。本轮不设置能力能量条或重复施放按钮，继续采用棋盘无空位的结束条件，不加入危险线和新的倒计时判负。

## 3. 晋级任务与判定时机

### 3.1 首版任务

首版以“本局实际合成出达到或超过目标的数字”跑通完整流程，默认目标为 1024。目标作为本局配置，可在 Inspector 调整为 2048，最终节奏由试玩确定。

| 条件 | 判定 |
| --- | --- |
| 目标 1024，本次合并产出 1024 | 完成任务 |
| 目标 1024，三颗 512 直接合成 2048 | 完成任务，不要求中间实际出现 1024 |
| 达标数字在同一手后续连锁中继续升级 | 保留达标结果 |
| 普通出子、显示数字、恢复节点或万能复制直接确定某数字 | 不作为新的合成事件；复制后真实发生的合并正常计入 |
| 同一手有多个组达标 | 只触发一次晋级 |
| 第二阶段再次合出同样数字 | 不重复扩盘或弹出同一次选择 |

现有多颗同值连通块合并规则保持：共 `n` 颗同值数字一次合并，结果为原值乘以 `2^(n-1)`。

### 3.2 其他任务的扩展方向

用户已经确认晋级可以由其他任务驱动，但尚未确定任务内容。候选包括累计完成指定次数的合并、一次落子达到指定连锁深度。它们属于后续可选内容，不列为首版必须实现的任务种类。

每局开始时固定本局晋级任务和目标。任务区展示当前目标与完成进度；不在对局中悄悄更换任务。

### 3.3 结算优先级

1. 完成本次操作引起的局部合并、重力和全盘结算。
2. 记录本次真实合并产物与任务进度。
3. 检查是否首次完成晋级任务。
4. 若晋级，先进入扩盘流程，再按新棋盘继续游戏。
5. 未晋级时，按当前棋盘检查满盘并决定是否结束。

因此，最后一个空位落子后即使旧盘面填满，只要本轮达成晋级任务，仍可扩盘继续。现有技能引发的真实合并也可完成任务，判定统一放在完整结算之后。

## 4. 镜头拉远与棋盘尺寸

### 4.1 尺寸建议

| 阶段 | 列数 | 行数 | 状态 |
| --- | --- | --- | --- |
| 第一阶段 | 5 | 7 | 当前默认棋盘 |
| 第二阶段 | 7 | 8 | 首版采用增加一行的建议值 |

首版采用 5×7 → 7×8，从 35 格增加到 56 格，新增 21 格；试玩时关注单局时长是否明显拉长。

### 4.2 棋子位置与视觉

- 建议左右各增加一列，新增行位于顶部；原棋子保留相互之间的排列。
- 按此建议，旧棋子的行索引保持，列索引统一加一，新增格子为空。
- 晋级时原棋盘、棋子、落点提示和棋盘内特效统一缩小，完整的新棋盘进入视野。
- 新棋盘一次增加两列，通过统一缩放呈现；不播放格子逐个生长或边框向外展开的动画。
- 得分、设置和道具栏沿安全区布局，缩放只作用于棋盘区域。
- 建议拉远演出约 0.6～0.9 秒，具体节奏随 Creator 预览调整；演出结束后展示三选一弹窗。
- 盘面在晋级时只迁移位置与尺寸，不重新洗牌、不清除棋子、不额外计分。
- 晋级不自动提高普通下落或快速下落的难度，避免棋子缩小后意外改变按格计算的下落节奏。
- 缩小后仍需保证数字可读、七列可点选、边缘列可区分，棋盘与 HUD、技能栏互不遮挡。

## 5. 三选一弹窗

采用三张横向纸卡纵排、统一确认按钮，静态布局位于 `assets/resources/base/Stage/StageChoicePopup.prefab`，可在 Creator 中编辑。原始视觉方向见[弹窗效果稿与手机预览](../design/晋级三选一弹窗/v1/README.md)。

### 5.1 卡片内容

标题建议“进入第二阶段”，说明建议“选择一项效果，继续挑战”。固定展示以下三项，不随机换入其他候选。

| 选项 | 类型标签 | 卡片说明建议 |
| --- | --- | --- |
| 斜向合并 | 本局持续 | 同值数字斜着相邻，也能自动合并 |
| 万能来客 | 本局持续 | 每隔若干颗出现万能数字，落地复制下方数字并参与合并 |
| 打乱 | 立即生效一次 | 将场上数字重新排列，寻找新的合并机会 |

两项持续增益和一项一次性效果必须明确标注，不能把打乱描述成永久可用。万能间隔确定后显示具体颗数；本文先以每 6 颗一次作为试玩建议。

### 5.2 选择规则

- 建议点击卡片选中，再点击“确认选择”；确认前可切换选项。
- 一局只选择一项，保存后再处理首次生效，不同时获得另外两项。
- 选择免费，不扣金币、体力、原有道具库存，不要求观看广告。
- 演出和弹窗期间冻结普通下落、快速下落、原有道具及棋盘操作，避免穿透。
- 点击遮罩不关闭，不设置倒计时，不自动替玩家选择。
- 斜向确认后立即启用并结算；万能启动后续出子规则；打乱确认后立即执行一次，不需要另选目标。
- 已确认的选择不会因没有立即合并而退回或重选。
- 当前打乱无法产生不同数值布局时，卡片置灰并说明原因，其余两项仍可选；确认时重新校验，不临时换入第四项。
- 第二阶段用轻量图标或文字显示本局选择。打乱完成后标记“一次性效果已生效”，不出现反复使用按钮。

## 6. 三项效果的规则

以下操作细节为首版建议，具体数值和边界处理仍可通过试玩调整。

### 6.1 斜向合并

持续时间：从确认选择开始，到本局结束。

- 同值连接从四向扩展到八向：上下左右和四个斜向相邻一格均有效，不跨越两格。
- 斜角两侧存在其他数值，不阻断该对斜向格子的连接。
- 同一同值连通块整体合并，不先四向算一次、再把同一组斜向棋子重复计算。
- 普通落子局部合并、后续连锁、全盘扫描及原有道具后的结算，统一使用本局邻接规则。
- 沿用现有局部锚点与全盘锚点，选择斜向不改变结果值公式或倍率。
- 确认后先按八向完成一次全盘结算，使旧盘面已有的斜向同值关系立即生效，再继续出子。
- 此次首次结算正常计真实合并分数，不消耗新数字；续局或恢复节点不再补算。
- 重力仍垂直向下，不增加手动横移或点选棋子的流程。

例：两颗 32 只有斜向接触时，选择后可合成 64；三颗 32 形成八向连通块时，仍按原公式合成 128。

### 6.2 万能来客

持续时间：从确认选择开始，到本局结束。建议每 6 颗一次，间隔为待调参数。

**特殊出子与计数**

- 选择后的第 6、12、18……颗普通出子替换为万能，每个序位仍只生成一颗。
- 确认后恢复出子的第一颗计为第 1 颗。已经展示的下一颗普通预览保留原值，不突然改成万能。
- 后续特殊序位提前在下一颗预览中显示“万能”与专用标记，玩家按正常方式选列。
- 仅在新当前棋子正式生成时推进序位，创建预览不另算一颗；万能本身也占一个序位。
- 暂停、无效触摸、道具、连锁中间产物、返回首页与节点重建不推进计数。
- 本局间隔与规则固定保存，续局不因新配置跳变。

**落地确定数字**

- 写入棋盘前复制最终落点正下方那颗数字的当前值，不从左右邻居中随机选值。
- 下方无棋子时变为 2，包括落在空列底部。
- 绑定后按当前四向规则完成本次普通落子的定向合并、重力和全盘结算。
- 复制动作不计合并奖励，之后真实发生的合并正常计分。
- 绑定后为普通数字，后续不再次复制；值以实际落地时的盘面为准。
- 下落中换列，或原有道具改变支撑数字后，复制最终位置下方的数字。
- 万能不同时获得斜向，首版两者为互斥选择。

例：万能落在 256 上方，先变为 256，再与下方正常合成 512；空列底部则作为普通 2 进入棋盘。

**显示与保存**

- 未绑定前显示万能标记，不用 0、负数或某个普通数字冒充其实际数值。
- 当前棋子和下一颗分别保存普通／万能类型；下落中返回首页，恢复后仍为万能，不能误恢复成 2。
- 稳定棋盘只保存已绑定的普通数字，不留下未解析的万能格子。
- 预览类型与实际生成一致，不在选列或恢复时重抽。

### 6.3 打乱

定位：确认选择后立即执行一次，完成后不保留再次施放的能力。

- 弹窗关闭后用 0.09 秒对方块做蓄力挤压，再用 0.42 秒收牌弧线和最多 0.10 秒的错峰，将方块带轻微旋转地收成一叠略微扇开的牌；不再全部缩小消失。
- 洗牌持续 0.78 秒，左右两叠交错穿插三轮，经过中线时交换前后层，伴随短促压缩、18ms 姿态停顿和冲击圈／碎点；随后用 0.10 秒叠齐并挤压蓄力。收牌、洗牌和未发出的牌始终可见。
- 每一颗从尚未满的列中独立随机选择，允许连续落同一列，不限制列高差；至少分到两列，底部填实不留空洞。落点与播放顺序一起生成，播放时不得按行列重新排序。
- 叠齐后每隔 0.085 秒发出一颗，先从牌叠用 0.065 秒短弧线抽出，再沿目标列以 0.115 秒高速垂直落下，带纵向拉伸和三道速度线。发出时有技能释放碰点，触地有明显挤压、短闪、回弹及地面冲击圈／碎点；0.10 秒还原大小，最后一份地面效果 0.16 秒结束后统一结算。未发出的牌留在牌叠中，不在发牌中逐颗触发合并。
- 此轮先做好消消乐式的动作反馈，音效留待后续接入，提供收牌、洗牌交错、发牌、触地四个触发时机。
- 重排完成、自动合并开始前，棋子数量和各数值数量保持，不直接清除或新增数字。
- 实际数值布局必须改变；相同数字只互换节点不算打乱。
- 场上不足两种不同数值时，无法得到不同布局，选项不可确认。
- 确认时生成不同的有效排列并固定结果，生成过程有界，不无限尝试。
- 重排后按原四向规则全盘合并与重力结算。真实合并可减少棋子数量，按现有规则计分。
- 不承诺一定合并或变好，卡片不使用“必定救场”等表述。
- 不消耗当前出子或预览，不额外获得斜向或万能。
- 选择、固定结果、一次性已用状态和后续稳定结果一起提交；动画中离场不重抽、恢复后不再打乱一次。

例：两颗 32 与两颗 64 重排后，这四颗数字在自动合并前仍完整保留；相同数字因重排相邻时，进入正常合并。

### 6.4 共同结算

- 首次生效与原有道具互斥，处理期间冻结普通下落。
- 真实合并正常计分并推进本局最高数字与任务，直接复制数值、迁移坐标和重排位置不重复算作合并。
- 完成全部重力和连锁后，才恢复出子或判断结束。
- 同一选择的首次处理只执行一次，重复点击、动画回调或恢复 UI 不重复生效。

## 7. 保存、续局与离场

### 7.1 必须保存的数据

| 数据 | 用途 |
| --- | --- |
| 本局规则版本、阶段、任务与完成进度 | 保留本局规则，不重复晋级 |
| 行列数与数字矩阵 | 恢复扩大后的完整盘面 |
| 待选择状态、所选类型、首次生效是否已提交 | 恢复弹窗或所选效果，防止重复处理 |
| 万能序位与固定间隔 | 保留距离下一颗万能的进度 |
| 当前／下一颗类型、普通值与下落位置 | 正确恢复普通／万能出子与预览 |
| 打乱已用状态与已提交结果 | 防止返回首页重抽或重复使用 |
| 原有分数、最高数字和道具状态 | 延续当前无尽对局 |

快照只保存纯数据，不持有节点、组件、函数或动画对象。仅对所选效果启用相应状态，不给其他选择附加效果。

### 7.2 中断与恢复

- 先保存扩大后的盘面与待选择状态，再播放镜头拉远。中途离场，恢复新盘面与待选择弹窗，不重复扩盘。
- 未确认选项时离场，保留待选择状态，不替玩家作决定。
- 确认斜向或打乱时，选择、首次生效稳定结果、分数与任务进度作为同一次操作提交；动画中离场恢复最终状态，不重复结算。
- 确认万能后保存选择和起始序位；恢复保留进度，不因重建节点多计一次生成。
- 斜向恢复后始终使用八向，不因恢复动画再次执行“首次启用”。
- 打乱恢复后继续四向普通落子，保留已用标记，不提供第二次使用。
- 后台冻结游戏，恢复当前稳定状态或待选择状态。
- 新开局回到默认 5×7、未选择；续局保留第二阶段尺寸与所选效果。
- 重复回调、重复释放不重复晋级、重排、计分或推进万能序位。

旧版 5×7 快照建议保留盘面与分数，按本局最高数字迁移合成目标进度，达标时补进一次晋级。迁移不使用账号历史最高数字、不补计分；具体策略随版本兼容方案确认。

## 8. 接入边界与现状限制

本节记录首版接入边界。

| 现有模块 | 涉及职责 |
| --- | --- |
| PlayController | 晋级编排、所选效果、统一邻接规则、万能出子与绑定、打乱及首次生效幂等 |
| BoardModel／EndlessProgression | 沿用棋盘矩阵与操作，纯数据模块维护阶段规则和重排，不引入第二份常驻组件棋盘 |
| BoardGeometry | 七列、新增行的坐标、触摸、落点和尺寸统一换算 |
| PlayUIController | 任务、拉远、三选一类型标签、选中标记与万能预览；只展示和回调 |
| OngoingGameSession | 动态尺寸、选择、万能类型与序位、一次性结果的纯数据续局 |
| ScoreManager | 沿用真实合并计分，未绑定万能不冒用普通数字参与最高值统计 |

- BoardConfig 上限已适配 7 列、8 行，布局、棋子尺度与快照矩阵同步更新；默认初始尺寸仍为 5×7。
- 当前会话配置与快照尺寸必须相同；晋级原子更新两者，不能调用新开局流程清空原盘面或重复扣体力。
- 拉远每帧通过统一布局入口刷新 UI 缓存和几何，七列显示与触摸使用同一尺寸。
- 棋子／下一颗和快照显式保存万能类型及序位，不用缺省值补成 2。
- 局部合并、能否合并检测和全盘扫描使用同一份本局邻接规则，避免只改全盘、落点仍按四向。
- 晋级取实际合并事实，不监听 UI 数字变化；当前最高值也会在普通出子时更新，不能替代合成事件。
- 静态弹窗在 Creator 维护，棋盘装饰沿用 ensureBoardDecorations()，外观沿用加载器与租约。
- 位图遵循 [UI 素材技能](../Skills/cocos-cream-ui-assets/SKILL.md)，已检查透明有效尺寸、运行时大小和体积；新增资源带独立 .meta，未重建旧资源 UUID。
- 动画、弹窗、首次结算与打乱离场时解绑监听、停止 Tween／回调并清理自有节点。引用检查有效性，异步回调检查宿主和代次，释放支持重复调用。
- 闯关保留独立场景和玩法脚本，不自动接入本轮效果。
- 当前云导入使用 ongoingGame: null；首版至少覆盖当前设备首页往返续局，不能据此声称已有跨设备或进程重启恢复。
- 扩盘与斜向、万能可能改变分数分布，上线前确定榜单版本策略；本文不默认重置榜单或调整正式接口。

| 打乱前后统计、列高度与空位 | 自动合并前数值数量保持，至少分到两列，允许重复列和不齐列高，不溢出、不悬空，数字布局确实改变 |

实现后按改动运行相关 tools/verify-*.cjs、Creator 自带 TypeScript 检查及 git diff --check；集合遍历覆盖 Creator loose 编译。脚本模拟不等同 Creator／微信真机验收。

### 9.2 试玩重点

- 1024 与 2048 哪个更适合作为首个晋级目标，触达需要多久。
- 斜向是否产生新落点选择，是否过快合空大面积棋盘。
- 万能是否有期待感、预览能否帮助安排落点，是否容易无限喂大同一颗数字。
- 一次性打乱的即时收益是否足以与两项持续增益形成取舍，有无长期无人选择的选项。
- 行列增加后的可读性、选列精度、单局时长与失败盘面。

首版可用试玩记录验证，不以新增分析后台为前置条件。

## 11. 方案调整记录
