## 最终实现

- `assets/resources/Settlement/SettlementPopup.prefab` 使用单张 result-card.png，皇冠、绶带、金边和静态标题合一，取消独立 Title Label。分数、同一行内的最高合成与金币、榜单 Mask、行模板和三个按钮由预制件维护。复用场景原有结算根节点及脚本 UUID。
- `GameOverOverlayController` 加载 Prefab、转发按钮、渲染真实数据和头像；场景与玩法背景不变。Prefab 失败时仍提供基础成绩和首页、重玩、分享。
- 弹窗新增 320ms 入场：遮罩 180ms 渐入，卡片由 94% 缩放和向下 22 设计单位的位置轻浮至最终位置，短暂到 101% 再落定，前 160ms 渐显。入场后才推进冲榜；异步加载不重复淡出遮罩，重算布局保持进度。关闭／停用／后台收敛到完整显示，减少动态效果时直接显示，不新增定时器或入场 Tween。
- 底部直接引用原场景的 `button-home-v3`、`button-replay-v3`、`button-share-v3` 三张 PNG，保留两枚方形图标和一枚横向分享按钮，126×126／126×126／316×126，按原素材比例与视觉尺寸排布。分享按钮按后续反馈改为蜂蜜金；图标、文字、显示尺寸与引用方式保留。
- `SettlementPresentation` 提供纯数据动画计算。本人从底部向上冲，周围玩家依次让位；八个对手行槽和一个本人行复用，不为全榜创建节点。
- 普通冲榜为准备 450ms、下压 180ms、飞行 1950ms、落位 340ms；超越 30 名以上将飞行设为 2100ms。大幅跃升压缩沿途真实片段，中段允许跳号，不使用虚构玩家。
- 普通超越两波共 96 片彩纸，持续 2600ms；登顶三波 144 片、3000ms；首次上榜一波 36 片、1900ms；持平和重放不庆祝。彩纸在落位开始时触发，采用单个 Graphics 绘制短彩带、星片和翻转纸片。
- 得分、头像、榜单、统计和按钮设置保护区域；彩纸不拦截点击。前三名复用已有奖章，其他名次显示动态数字。减少动态效果直接显示最终位置。
- 上方显示本局得分，本人行显示已验证历史最佳；主分数与榜单分数均加千分位，支持 1,000,000,000 完整显示。主分数字号收为 76、字框 570×96，单行 SHRINK；榜单分数右对齐、昵称超宽省略。
- 最高合成缩略图显示本局数字并同步棋盘颜色，和棋子共同读取 PieceStyle；512 为紫色，不再固定成绿色空块。图标与标题字框留 6 设计单位，标题与数值至少留 12，图标／文字／数值保持同一垂直中心；0 值时隐藏缩略图。
- 顶部始终显示「第 N 名」与实际 `↑N`；登顶仍保留「第 1 名」，只在「分数排行」右侧显示小号、常规字重的「已登顶」。持平无上升箭头，整个名次组居中。
- 布局基准 750×1360，按可用宽高等比缩放；复用 UI 主控已有的微信胶囊和系统安全区读取，避让顶部和底部。榜单视口 632×500，行 608×90、节距 96；榜单内没有奖杯或填充插画。遮罩覆盖完整画布。
- 每份快照仅消费一次；重开、返回、停用、销毁、后台时停止动画、清空彩纸、释放头像与按钮 Tween。隐藏后到达的旧局回执不能进入新局。

## 后端与数据

在现有 `/sync` 响应新增可选 `settlement`，保留旧 `rank`，无新请求参数和数据库迁移：

```ts
{
  operationId: string;
  previous: number | null;
  current: number | null;
  self: LeaderboardEntry;
  entries: LeaderboardEntry[];
  celebrate: boolean;
}
```

- 只对应该批次最后一条 `game_finished`，客户端严格匹配操作 ID。之前补传的对局先合并，最后一局的起点取其执行前的历史最高分名次，避免混用整批增量。
- 名次、资料、成绩更新和快照保存处于同一事务；条目使用公开榜口径：已验证正分、活跃账号，分数降序、同分按玩家 ID 升序。
- 最多七段、56 条对手记录；本人单独返回。起点与终点附近连续，中段采样。头像复用内置与微信头像渲染器，异步加载不阻塞动画。
- 相同请求和操作重放均收敛为 `previous=current`、`celebrate=false`。首次上榜起点为 null，零分不上榜；校准不返回新版结算字段。
- 三秒无回执时结束等待，显示基础结算与排行未更新状态；继续允许返回、重开、分享。旧服务仅有 `rank` 时回退为名次文字，不编造榜单。
