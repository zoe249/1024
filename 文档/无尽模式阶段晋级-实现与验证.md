# 无尽模式阶段晋级：实现与验证

日期：2026-11-02。

2026-11-03 更新：一次性打乱改为“弧线收牌 → 左右两叠交错洗三轮 → 逐张随机发回”，牌全程可见；落点继续逐颗独立随机选择。

无尽模式已接入一次晋级：真实合成达到目标后，先完整结算，再播放拉远动画，弹出斜向／万能／打乱三选一。独立闯关模式保持原流程。

## 使用与参数

- 默认合出 **1024** 晋级，跨级合出 2048 也算达标。`game.scene` 中 `PlayController.stageTargetValue` 可调整为 2048。
- 默认 **5×7 → 7×8**：左右各加一列，顶部加一行，原行列关系保持，新增格为空。
- 拉远 **0.80 秒 sineInOut**，底边固定，棋盘与棋子连续缩小，HUD 和技能栏按原安全区显示。按格下落速度随尺寸同步缩放。
- 弹窗入场：遮罩 0.20 秒渐显，面板 0.16 秒渐显，0.24 秒弹入加 0.10 秒收稳；关闭 0.18 秒上移缩小并淡出。
- 无默认选中；点卡片后亮起选中标记和确认按钮。遮罩阻断穿透，演出与弹窗期间冻结普通下落及道具操作。

| 选项 | 本局效果 |
| --- | --- |
| 斜向合并 | 立即按八向结算一次；此后局部连锁、全盘扫描和道具后结算统一按八向 |
| 万能来客 | 选择后从第一颗计数，每第 6 颗为万能；落地复制正下方数值，空列落底变为 2，随后正常合并。`wildcardInterval` 可调 |
| 打乱 | 一次性回收全部已落地数字，再逐颗分散回落到不同列，保持数量和数值集合，全部落定后按四向结算；无法形成不同排列时置灰 |

打乱动画由 PlayEffects 的单一 Tween 时间轴驱动。先用 0.09 秒蓄力挤压，方块沿二次贝塞尔弧线、带轻微旋转收成扇开的牌叠，起步时拉伸释放；单颗收牌 0.42 秒，整组错峰最多 0.10 秒，保持不透明。

随后左右两叠交错洗牌三轮，共 0.78 秒；牌叠拉开、反向换边并轻微旋转，在中线交换前后层、按左右半叠交错插入。交错点加入 18ms 姿态停顿、短促压缩、扩散圈与碎点；仅调整牌的动作，不暂停引擎。起止运动渐入渐出，之后用 0.10 秒叠齐并挤压蓄力。只调整 PieceLayer 内棋子的临时层序，不影响 HUD。

每隔 0.085 秒发一颗：从牌叠以 0.065 秒短弧线抽出，再从目标列上方以 0.115 秒高速直落，飞行中拉伸为宽 0.72／高 1.5 倍，配三道竖向速度线。首次发出带释放碰点；触地压至宽 1.24／高 0.72 倍，短闪后回弹，0.10 秒还原大小，底边锚定；地面扩散圈和碎点持续 0.16 秒。结束后恢复位置、朝向、大小与皮肤底色。未发出的牌始终留在牌叠里。

速度线、冲击圈和碎点共用一个临时 Graphics 节点，结束、停用和清理时释放。无新增贴图或音频资源。

本轮只做视觉反馈，不自动播放洗牌音效。后续在 `PlayController.finishStageEffect()` 调用 `PlayEffects.playShuffleRedeal()` 时传入可选第四参数 `onFeedback(cue)`，即可按下表接入音效；同帧跨过多个发牌或落地时刻时合并反馈，避免叠响。

| cue | 触发时机 |
| --- | --- |
| gather | 蓄力结束、开始收牌，仅一次 |
| shuffle | 牌叠交错换层的碰点 |
| deal | 抽出发牌 |
| land | 触地开始挤压 |

每一颗独立从未满列中随机选择，允许连续同列与不齐列高；只有“即将全部落同一列”时让最后一颗落入其他列。每列从底部填实，不溢出、不留悬空格。数字布局若恰好与原来相同，以一次异值交换保证变化，不无限重抽。

`shuffleBoard()` 一次返回最终棋盘和随机落点序列；PlayController 将该序列原样交给动画，不能再按行列扫描排序。序列属于本次演出，最终棋盘先提交到续局快照；中断恢复跳过演出，直接沿用固定棋盘结算，无需重新抽取落点。

## Creator 入口与资源

- 弹窗：[StageChoicePopup.prefab](../assets/resources/base/Stage/StageChoicePopup.prefab)。面板、三张卡片、标签、图标和确认按钮均为静态节点，文字未烘焙。可直接在 Prefab 模式编辑。
- 展示控制：[StageChoicePopupController.ts](../assets/script/gameplay/StageChoicePopupController.ts)。只管理布局、动画与回调。Creator 3.8 Graphics 不跟随 UIOpacity，遮罩同步重绘自身 Alpha。
- 规则纯数据：[EndlessProgression.ts](../assets/script/gameplay/EndlessProgression.ts)。保存阶段、目标、选择、万能序位，提供邻接和有限次数的有效重排。
- 编排：[PlayController.ts](../assets/script/gameplay/PlayController.ts)。在完整结算后、旧满盘判负前晋级。坐标继续使用 BoardGeometry；棋盘装饰仍只走 ensureBoardDecorations。
- `game.scene` 仅新增静态阶段任务文字；旧场景节点、Prefab 与资源 UUID 保留。弹窗通过 `resources` 加载并持有独立资源引用，离场释放。
- Prefab 维护脚本：`node tools/create-stage-choice-prefab.cjs`。重新生成会覆盖该弹窗的手工布局，日常优先直接在 Creator 维护；已有资源 UUID 不重建。

## 续局与中断

阶段、当前／预览万能类型、序位、已确认选择随 OngoingGameSession 保存。首页往返保留 7×8 和所选效果，新开局回到第一阶段，不因扩盘重新扣体力。

拉远前保存最终尺寸的待选择快照；打乱确认后先固定回落排列和结算起点，再关闭弹窗并播放回收与逐颗回落。中断恢复直接按已固定结果结算，不重抽、不重复计分。停用取消自身时间轴并结束待完成 Promise，晚到回调检查时间轴身份和宿主代次；子节点先毁和重复清理检查引用有效性。

该会话沿用项目现有内存续局，覆盖当前进程首页往返；不新增进程退出持久化或跨设备存档能力。
