# 体力条优化实现与验收

日期：2026-10-09。前后端保留 `codex/energy-recovery-design` 工作分支；本次完成源码实现与隔离验证，没有提交、推送或部署服务，没有数据库结构迁移。

## 实现

- 复用 `assets/prefab/EnergyBar.prefab` 路径及原 UUID。主条由独立 Label 显示数值；恢复中显示下挂时钟与倒计时，满体力显示无底板「体力已满」。状态切换不移动主条，确认单点恢复或奖励后只播放一次飘字。
- 根据小屏截图反馈，倒计时最终采用 22 号字，下挂标签节点采用 112×40；宽度保持紧凑，高度增加，数字在标签内垂直居中，保留上下留白。数字位置为 x=13、y=0，时钟与数字的可见间距约 10 个设计单位；整组水平居中，左右内边距约 15 个设计单位。底图按新高度重新生成，源图与节点等比缩放，时钟保持圆形；主条位置不变。
- 新增 `EnergyBarController`，仅接收 `EnergyBarState` 与获取入口回调。主条和加号通过同一根节点事件处理，避免重复回调。隐藏或销毁时停止 Tween 并解绑。
- `home.scene` 的 `Canvas/Main/StartPageOverlay/PageCard/HomepageArtwork/EnergyBar` 静态放置关联预制件实例，`StartPageController.energyBarNodeRef` 绑定该实例。体力数值、倒计时、满状态和飘字节点可在层级管理器中编辑；原预制件 UUID 保留，补齐节点与组件的预制件对象标识。编辑器中的 `8/10`、`04:49` 是布局示例，进入运行后由经济状态覆盖。
- `StartPageController` 的首页层级模式不再创建或迁移体力节点，内部布局与字号不由脚本覆盖；运行时只进行屏幕/安全区适配、状态更新、点击和动画。横坐标保留层级中的值，飘字以编辑器里的位置为动画起点。没有静态首页层级的历史入口保留兼容兜底。旧 `StaminaResource` 保留但停用；金币位置不变。
- 首页背景只绑定首页根下的专用容器，不再递归匹配所有同名 `Background`；新版首页的背景只走自身的 cover 适配，避免体力条内部底图被旧背景逻辑误拉伸到全屏。
- `HomeSceneController.openEnergyAcquire()` 保留现有分享能力，未新增未确认商业规则或空白获取弹窗。
- 登录账号不进行本地自然恢复入账，采用服务端 UTC 时间与运行期单调时钟估算倒计时；未知锚点显示 `--:--`。游客保留本地恢复，但修正未满消费重置周期的问题。
- 跨首页和玩法合并同步；倒计时到零触发一次同步，失败按 5、15、30、60 秒退避，平时约 60 秒校准。前后台、微信和 Web 网络恢复均接入，后台不重复请求，组件释放时退订全局监听。
- 新开和重玩等消费回执通过后再建立新对局；网络请求失败可用缓存确认额度形成未确认消费。401 时保留同一消费意图，恢复登录后复用 operationId。续局不扣费。
- 分享体力和金币均等待服务端回执；HTTP 成功不会被当作所有操作均已接受。离线消费被拒绝时显示原因，不清空当前棋盘。
- 确认快照按修订号及校准时间过滤旧响应，再重建仍未确认的消费、技能、签到和对局结果。首次游客导入只移除本次捕获的操作，保留在途新增操作；三批之后剩余队列继续调度；登录账号队列不再按 200 条截断。
- 经济缓存和队列继续按接口地址隔离，并增加账号维度；旧环境存档只迁移给首个账号，后续账号不会带入上一账号的余额或待确认操作。
- 后端在账号锁之后取得一致时间，消费与奖励先结算到期恢复。满→未满启动 300 秒周期，未满消费保留余量。兼容返回 `energyRecoverySeconds` 和 `nextEnergyRecoveryAt`，已有请求结构不变。
