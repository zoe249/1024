# 静态素材体积报告

优化基准：项目设计分辨率为 750×1335；静态素材按界面实际显示面积保留约 1.5～2 倍采样，不再保存生成器原始分辨率。

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 32 个静态素材 | 25.69MB | 1.13MB |
| 首页设置按钮 | 616.8KB | 8.7KB |
| 小鸟角色 | 956.3KB | 20.1KB |
| 功能卡 | 793～1003KB/张 | 24～35KB/张 |
| 结算按钮 | 1.26～1.47MB/张 | 34～35KB/张 |
| 首页背景 | 1.95MB | 275.4KB |

处理策略：

- 小图标控制在 144～256px。
- 功能卡控制在 320～384px 宽。
- 横向按钮控制在 512～640px 宽。
- 大型标题与统计条控制在 768～900px 宽。
- 透明素材保存为 256 色索引 PNG，并保留透明通道。
- 无透明需求的全屏背景保存为 750px 宽、质量 88 的渐进式 JPEG。
- 动画素材本轮未处理。

透明边缘、四角透明度和素材总览均已检查。优化脚本为 `optimize_generated_materials.py`。
